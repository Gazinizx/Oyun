# Reklam Ödülü

Basit, dokunarak altın toplama ve yükseltme temalı mobil mini oyun prototipi.

## Özellikler
- Tek dokunuşla altın toplama
- Güç yükseltmesi ve sürpriz sandık
- Görev ilerlemesi ve cihazda yerel kayıt
- Android APK için GitHub Actions iş akışı
- iOS Simulator derlemesi için ayrı iş akışı

## Derlemeler
GitHub'da Actions sekmesinden Android APK iş akışını açın. Tamamlandığında Reklam-Odulu-APK artifact'ini indirin. iOS iş akışı simülatör içindir; App Store dağıtımı için Apple geliştirici imzalama ve provisioning gerekir.

Not: Bonus reklam düğmesi şimdilik demo ödülü verir; gerçek reklam ağı SDK'sı entegre edilmemiştir.
